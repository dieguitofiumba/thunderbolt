# ⚡ Thunderbolt SIGA
### Servidor Intermedio Gestor de APIs

> [!IMPORTANT]
> **ESTE ES EL MD ACTUALIZADO:** Este repositorio se mantiene únicamente con fines históricos. Fue mi primer despliegue de backend cuando aún estaba aprendiendo las bases de **Node.js** y la arquitectura de servidores. Representa el inicio de mi camino en la lógica de programación y el manejo de APIs.

---

## 🏛️ Descripción Original (Legacy)
*La siguiente descripción fue escrita cuando el proyecto estaba activo:*

> **SIGA** es un servidor backend intermedio encargado de procesar y manejar solicitudes a APIs externas de manera eficiente, lo que permite alta **compatibilidad** con distintos servicios estáticos.

## 🧠 Lo que aprendí aquí
Aunque hoy escribiría el código de forma distinta, este proyecto fue fundamental para entender:
* La estructura de un proyecto Backend.
* Cómo conectar una web estática con servicios externos.
* El flujo de datos entre servidor y cliente.
